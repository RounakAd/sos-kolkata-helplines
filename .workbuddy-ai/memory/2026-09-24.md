# 2026-09-24 — Kolkata SOS emergency directory

## What was built
Single-file static site (`index.html`) — one-stop SOS emergency directory for Kolkata,
West Bengal. Deployed via GitHub Pages. No backend, no build step, no runtime API calls.

## Project conventions (decided this session)
- **No dummy/placeholder data, ever.** Every number is a real, government-published
  helpline with its source recorded on the card.
- **Directory data is bundled, not fetched live.** `data/kolkata-sos.json` holds hospitals
  + police stations. The page reads it with a relative path (`data/kolkata-sos.json`) so
  it works from a GitHub Pages sub-path.
- `build-data.mjs` (Node 18+, zero deps) regenerates that JSON from OpenStreetMap.
  Run manually: `node build-data.mjs`. Committing the refreshed file is the deploy.
- Local preview must be served over HTTP (`python -m http.server`), not `file://` —
  browsers block local JSON reads.

## Structure
- Tabs: **Helplines** (default), **Hospitals**, **Police Stations**, **Women's Safety**.
- Top strip = 12 priority helplines (112, 100, 101, 102, 1091, 181, 1930, 1033, 1073,
  139, 1098, 14567). Fire / ambulance / cyber / breakdown live here + in the Helplines tab.
- Police tab is deliberately **name + Google Maps only** — OSM has almost no PS phone
  numbers, so no Call button is shown for stations.
- Helplines tab has 9 groups: emergency, women, cyber, railway, disaster, child,
  elderly, road, misc.

## Gotchas worth remembering
- **Overpass mirrors:** `overpass-api.de` returns **HTTP 406** without a `User-Agent`
  header. `overpass.osm.ch` is Switzerland-only and silently returns 0 rows.
  Working global mirrors: `maps.mail.ru/osm/tools/overpass/api/interpreter`,
  `overpass.kumi.systems`, `overpass.private.coffee`.
- **Overpass rate-limits per IP.** Firing 6 parallel category queries fails; one combined
  union query succeeds. Heavy test volume gets the IP temporarily blocked.
- The dataset bbox is 22.42–22.70 N, 88.20–88.50 E (Kolkata metro), so a few
  Bidhannagar / South 24 Parganas entries appear.

## Testing approach used
Headless Chrome via CDP (`browser-visual-audit` skill) + a Node probe script:
structure assertions, tab sweep at 1440/820/390/340 px checking `scrollWidth > innerWidth`,
geolocation stubbed with `Emulation.setGeolocationOverride`, screenshots read back visually.
Caught two real bugs this way: a `debounce()` helper passing `null` as `this` (broke the
search box entirely) and a hero counter that only updated on the active tab.

# 2026-09-24 (later) — Pet Care tab, NGOs, more helplines

## What changed
- **New tabs:** now 6 — Helplines · Hospitals · Police Stations · **Pet Care** · **NGOs** ·
  Women's Safety. Toolbar (search/sort/callable/locate/reload) shows on hospitals, police
  and petcare only.
- **Pet Care tab** = OSM veterinary/shelter records (location + address only, no Call button
  when there's no phone) + 7 animal welfare orgs that DO have phone numbers.
- **NGOs tab** = 23 cards across 7 groups (children, girls, women, elderly, disability,
  animals, drugs), with a prominent "not emergency services" disclaimer.
- **Siren made much louder:** two detuned oscillator layers (sawtooth + square),
  master gain ramped to 1.0, through a `DynamicsCompressor` acting as a limiter so it
  doesn't clip. Old version was a single osc at gain 0.22.
- **Data file now has 3 layers:** hospitals (331), police (43), petcare (3) = 377 records.

## Deliberate omission
**1094** is widely quoted online as a "missing child helpline" but I could NOT confirm it
from any government source (checked india.gov.in, district .gov.in sites, WCD). So the
Missing persons group uses 112 / 100 / 1098 / 1091 / 181 plus a link to the official
Kolkata Police Missing Person portal instead. Don't add 1094 without a real source.

## NGO sourcing rules (keep these)
Only include an org if its details come from **its own website** or a credible public
directory, and record the source on the card. Verified from own sites: CINI
(cini-india.org), Sanlaap, Manovikas Kendra, IICP (iicpindia.org/contact), Kripa
Foundation, ABWU, Little Sisters of the Poor. Animal orgs came from
voicelessindia.org/kolkata-animal-helplines. `NGO_ORGS` is a flat array with a `causes`
array — groups filter it, so an org serving several causes isn't duplicated in code.

## OSM coverage reality check
Kolkata OSM has almost no `amenity=veterinary` (3 in the bbox, 0 with phones), no
ambulance stations, no towing, no cyber cells. Widening the bbox to 22.35–22.80 /
88.10–88.62 only found 1 more vet. Don't expect Overpass to fill these categories.

## UI note
Official helplines whose number happens to be a 10-digit mobile get a WhatsApp button, but
the chip says **"Mobile line"** not "WhatsApp ready" and the button carries a tooltip —
official lines are unlikely to be monitored on WhatsApp.

# 2026-09-24 (later still) — count fix + real ringtone

## Bug fixed: tab counter jumped on click
`updateCounters()` set the Pet Care badge to `state.petcare.length` (3, the mapped clinics)
while `renderPetPanel()` overwrote it with clinics + animal orgs (10). So the number changed
the moment you opened the tab. Added `animalOrgs()` and `petcareTotal()` helpers and used
them in **both** places. **Rule: a tab badge must be computed by one shared function, never
in two places** — any panel that shows extra non-dataset cards (like Pet Care) must feed that
total into `updateCounters()`.

## Fake-call ringtone rebuilt
Was a single 480 Hz sine beeped every 1.8 s at gain 0.16 — not recognisable as a phone.
Now a genuine ring: **440 Hz + 480 Hz sounded together**, amplitude-modulated by a **20 Hz
LFO** for the bell trill, in a **2 s on / 2 s off** cadence, through a `DynamicsCompressor`
limiter at gain 0.95. `stopRing()` fades and tears down all nodes; both the answer and end
buttons call it. Verified by instrumenting `AudioContext.prototype.createOscillator` in the
browser — 3 oscillators at exactly 440 / 480 / 20 Hz, 1 compressor, `audioCtx.state === "running"`.
